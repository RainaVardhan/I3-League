## The model in brief

- **Six stages, in order:** INSIGHT → INVESTIGATE → IMAGINE → ITERATE → IMPACT → INFLUENCE. No IP Checkpoint.
- **Four layers per stage:** LEARN → DO → SHOW → REVIEW, with a Feedback → Revise → Resubmit → Advance cycle on top.
- **One common pathway** for all grades; depth is set by `CORE — ALL` / `HS CORE` / `STRETCH` tags, not separate middle/high-school curricula.
- **Four frozen principles:** evidence over hype; revision is expected, not punished; an unsuccessful solution can still be excellent innovation work; judges evaluate the journey, not the polish.
- **Review is a floor-based gate**, not an average: advance only when all six rubric dimensions are at least "Meets Standard."
