# i3League — Layer 3: SHOW — Master Artifact & Submission Table

**Rule:** Students do not submit every worksheet as a separate competition artifact. Worksheets are working tools. The stage artifact is the polished evidence package that shows what the student learned and did.

---

| Stage | Required Artifact | Required Submission Contents | HS / Stretch Additions | Advancement Requirement |
|---|---|---|---|---|
| **1 INSIGHT** | Validated Problem Statement + Evidence Notes | Problem statement, affected group, observation evidence, firsthand interview evidence, scope rationale, team charter | None required | Problem is specific, evidenced, not a disguised solution, and student can explain why it matters |
| **2 INVESTIGATE** | Research Brief | Research questions, survey/interview evidence, source list, triangulation, root cause analysis, existing-solutions gap, stakeholder map | System Map for HS | Multiple evidence types, honest findings, credible root cause, clear gap in existing solutions |
| **3 IMAGINE** | Concept Portfolio | Value proposition, needs/features map, 3+ concepts, constraints, risks, accessibility/ethics, AI fit if relevant, originality/IP record, decision matrix, selected concept, critical assumption | Build/Buy/Partner for HS | Multiple real options considered, selection justified, originality disclosed, critical assumption named |
| **4 ITERATE** | Tested Prototype + Test Plan + Iteration Log | MVP definition, prototype, test question, success criteria, participant/test plan, observations, feedback, learning log, revisions, version history, retest evidence | Formal Experiment Design + Git/README when relevant | Critical assumption tested, evidence collected, revision made, revised version retested |
| **5 IMPACT** | Impact Report | Impact statement, success metric, baseline/benchmark/comparison, result, quant/qual evidence, analysis, limitations, unintended consequences, stakeholder impact, cost/benefit, final evidence-based conclusion | Adoption/Uptake, Scalability, ROI/Unit Economics, Advanced Analysis | Conclusion matches evidence, even if impact was not achieved |
| **6 INFLUENCE** | Final Pitch + Innovation Portfolio | Audience plan, story arc, visuals, demo, evidence defense, Q&A prep, implementation/sustainability model, clear Ask, reflection, complete portfolio | HS: budget, funding, partnerships, risk, executive summary; Stretch: GTM, sizing, architecture | Finals-ready story, defensible evidence, realistic next step, strong Q&A, team-wide ownership |

---
