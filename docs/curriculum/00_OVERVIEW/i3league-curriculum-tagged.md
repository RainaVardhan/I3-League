# i3League Curriculum — Tagged by Depth

**Philosophy:** All students follow the same six-stage innovation journey. Depth increases by grade level, project complexity, and student readiness.

**Tags:**
- **CORE — ALL** — required for every student
- **HS CORE** — required for high school students
- **STRETCH** — advanced enrichment for strong/older students or complex projects

The topic list is now considered complete and matches the final six-stage LEARN curriculum exactly, topic for topic. Further additions would reduce clarity rather than improve rigor. The next layer of work is operational, not topical.

## Artifact → Advancement → Reviewer Evidence

| Stage | Artifact | Advancement Requirement | Reviewer Evidence |
|---|---|---|---|
| INSIGHT | Validated Problem Statement + Evidence Notes | Specific problem + affected group + firsthand evidence | Interview/observation evidence |
| INVESTIGATE | Research Brief | Multiple evidence types + root cause + gap | Citations, data, stakeholder evidence |
| IMAGINE | Concept Portfolio | Multiple concepts + decision + critical assumption identified + originality/attribution disclosed | Decision matrix |
| ITERATE | Tested Prototype + Test Plan + Iteration Log | Real test + feedback + documented revision | Before/after evidence |
| IMPACT | Impact Report | Meaningful metric + baseline/benchmark/comparison + measured result + honest limitations | Data |
| INFLUENCE | Final Pitch + Innovation Portfolio | Clear story + evidence + implementation model + Ask | Live pitch/demo |
